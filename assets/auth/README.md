# Sign-in assets

- `google-g.png`: the unmodified Google G from Google's [Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines), downloaded from `https://developers.google.com/static/identity/images/g-logo.png`. Google owns this trademark; use only for the Google sign-in button and preserve its colors and proportions.
- `GoogleSans-Medium.ttf`: Google Sans Medium from [Google Fonts](https://fonts.google.com/specimen/Google+Sans), restricted by Google's font endpoint to the eight translated Google button labels. Distributed under the included `OFL.txt`; other app text continues to use system fonts.

No provider credentials belong in this directory.
